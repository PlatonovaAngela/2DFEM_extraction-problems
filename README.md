# 2DFEM

Программа для решения двумерных задач метода конечных элементов (МКЭ).

## Зависимости

- **CMake ≥ 3.24**
- **Компилятор с поддержкой C++17**
  - Windows: Visual Studio 2022 (MSVC)
  - Linux: GCC / Clang
- **Eigen 3.4** — библиотека линейной алгебры

&gt; Eigen **не нужно устанавливать вручную**: при первой конфигурации
&gt; CMake автоматически скачает исходники Eigen 3.4 через `FetchContent`
&gt; в папку `sdk/` рядом с проектом. Подключение производится как
&gt; header-only библиотека — отдельно собирать Eigen не требуется.

## Сборка

### Windows

Запустите скрипт:

```bat
build.bat
```

### Linux
Запустите скрипт:
```sh
build.sh
```
